# Markdown como língua franca

## Em uma frase

Markdown é texto com poucas marcações que a pessoa lê bem, a IA lê bem e qualquer ferramenta abre; por isso é a língua em que a pasta, as instruções e as saídas devem estar escritas.

## Como explicar em dois minutos

1. **Língua franca** é o idioma que pessoas de línguas nativas diferentes adotam para se entender. Numa região onde ninguém é inglês nem americano, mas todos falam inglês para negociar, o inglês é a língua franca.
2. Entre você, a IA e as ferramentas, a língua franca é o Markdown. Não é código e não é texto puro: é texto com marcações simples (`#` para título, `-` para lista, `**` para negrito).
3. Para você, é bom: dá para ler e editar em qualquer editor, e o título continua parecendo título. Para a IA, também: as marcações dizem o que é título, lista e citação. Para ela, escrever formatado ou sem formato custa praticamente o mesmo.
4. O PDF é o contrário. Cada PDF vem de um jeito (colunas, cabeçalhos, imagem escaneada), e a IA gasta muito mais para ler, toda vez que abre. Quem trabalha com dezenas de artigos paga isso em qualidade e em créditos.
5. O caminho é converter uma vez e trabalhar sempre em texto. Quem não faz isso costuma descobrir sozinho depois de meses gastando; a oficina adianta essa descoberta.
6. A conversão é **outra máquina**. Não embuta um conversor de PDF em cada pasta: tenha uma pasta (ou ferramenta) que transforma PDF, planilha ou imagem em `.md`, e deixe as outras pastas receberem só texto.

## Analogia ou imagem

A língua franca de um porto. E, para a conversão, a máquina de casquinha, que fica separada da máquina de sorvete: se cada máquina de sorvete fabricasse a própria casquinha, seria mais uma peça para quebrar dentro dela.

## Fala-chave

"Não é um arquivo de código e não é texto puro. É texto com marcações. Bom para você, bom para a IA."

"O PDF, a IA lê de novo, e de um jeito diferente, toda vez. O Markdown, ela lê igual."

## Erro comum que o conceito corrige

Jogar os PDFs direto na conversa ou na pasta, a cada tarefa, e achar que a IA "piorou" quando o problema é a entrada. Ou o erro oposto: montar uma pasta que faz fichamento *e* conversão *e* formatação, e não saber onde está o defeito quando algo sai errado.
